│   ├── WinAudit/           audit heuristique local (lecture seule)
│   └── DiskMap/            carte disque · gros fichiers · doublons

├── system/                 AudioDevice · FocusBlock · MonitorInfo · PowerPlan

`private · AI-built · human-tested`
